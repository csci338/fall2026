## Suggested module/action bank

- **R1 — Trace and reason:** assign the relevant worked traces from Modules 1–4; require branch decisions and variable/collection state after every iteration.
- **R2 — Control flow:** assign Module 1 (Java methods and conditionals), Module 2 (loops, counters, and accumulators), and Module 5 when edge-case reasoning is also missing.
- **R3 — Lists/arrays:** assign Module 3 (lists/arrays and traversal) and Module 5 (simple algorithms and edge cases).
- **R4 — Maps/sets:** assign Module 4 (maps/sets and frequency counting) and Module 5 for algorithm-selection practice.
- **R5 — Test/debug:** assign Module 6 (testing and debugging); require representative and edge tests with expected results plus one evidence-based repair.
- **R6 — Explain/revise:** require the exit explanation from each assigned module and Module 6's correction record; use the typed follow-up for official reassessment evidence.
