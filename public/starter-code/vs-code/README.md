# Turn editor AI off

Use this when VS Code keeps offering Copilot, Codex, Claude, or similar tools.

```bash
python3 toggle-editor-ai.py off
python3 toggle-editor-ai.py on
```

Then reload VS Code (**Developer: Reload Window**).

This changes **user** settings, so it applies to every folder. Full directions: [Turn Off Editor AI](/resources/disable-editor-ai).
