# Diagnostic (Java)

Fill in the TODOs in `Diagnostic.java`. Do not change `DiagnosticTest.java` or `Card.java`.

## Methods

1. `groupByFirstLetter` — group words by first letter
1. `targetSum` — true if two different spots add to the target
1. `countDistinct` — how many different numbers
1. `hasThreeOfAKind` — true if any card rank appears 3 or more times

The full questions are on the [diagnostic page](/resources/programming-readiness-diagnostic).

## Run the tests

Keep these three files in the same folder.

```bash
javac Diagnostic.java DiagnosticTest.java Card.java && java DiagnosticTest
```

You should see `Passed 15 tests.` when everything works.
