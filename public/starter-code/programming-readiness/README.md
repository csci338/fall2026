# Programming readiness starter code

This folder has practice files for the Programming Readiness diagnostic and modules.

Pick **Java or Python**. Stay with that language.

| Folder | What you write |
| --- | --- |
| [diagnostic-java](diagnostic-java/) | Diagnostic methods in Java |
| [diagnostic-python](diagnostic-python/) | Diagnostic methods in Python |
| [module-01](module-01/) | Can a flower be planted here? |
| [module-02](module-02/) | Loops that count |
| [module-03](module-03/) | Nested loops over a list |
| [module-04](module-04/) | Group words with a map |
| [module-05](module-05/) | Anagrams and target sum |
| [module-06](module-06/) | Fix broken tests |

Each folder has a README with run commands.
